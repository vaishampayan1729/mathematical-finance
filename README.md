# Mathematical Finance

Mathematical foundations, numerical experiments, and Python implementations in quantitative finance.

## Overview

This repository explores mathematical finance through theoretical notes, computational demonstrations, and independent numerical experiments.

The project begins with [MIT 18.642 — Topics in Mathematics with Applications in Finance (Fall 2024)](https://ocw.mit.edu/courses/18-642-topics-in-mathematics-with-applications-in-finance-fall-2024/) and will gradually expand to include stochastic processes, stochastic differential equations, financial time series, portfolio optimization, risk modeling, and machine learning applications in finance.

## Objectives

- Develop mathematical notes with definitions, examples, derivations, and exercises.
- Implement mathematical and statistical models using Python.
- Reimplement and extend numerical demonstrations originally presented in R.
- Investigate model assumptions through simulations and empirical experiments.
- Develop reproducible computational research in quantitative finance.

## Tools

Python, NumPy, SciPy, pandas, Matplotlib, statsmodels, scikit-learn, and PyTorch.

## Repository Organization

- `notebooks/` — Mathematical notes and computational demonstrations.
- `experiments/` — Independent numerical investigations.
- `src/` — Reusable Python implementations.
- `data/` — Local datasets and data documentation.
- `figures/` — Generated visualizations.
- `tests/` — Tests for reusable implementations.
